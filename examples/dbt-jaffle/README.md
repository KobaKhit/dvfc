# Jaffle Shop Analytics Dashboard

Real dbt-shaped example based on the classic [dbt jaffle_shop](https://github.com/dbt-labs/jaffle_shop) project.

## Real dbt Project Layout

This example demonstrates the **recommended layout** for using Data Viz Factory with a real dbt project:

```
my-dbt-project/
├── models/
│   ├── staging/
│   └── marts/
│       └── customer_orders.sql    # Your mart models
├── target/
│   └── manifest.json              # Generated by dbt parse/run
├── seeds/
│   └── dashboard_data/            # Optional: exported CSVs for viz
│       └── customer_orders.csv
└── dvfc/                          # Dashboard configs
    ├── *.dash.yaml                 # Your dashboard spec
    └── dbt-stub/                  # Symlink or copy
        ├── manifest.json          # → ../target/manifest.json
        └── *.csv                  # → ../seeds/dashboard_data/
```

**Key pattern:** Keep dashboard configs in a separate `dvfc/` directory alongside your dbt project.

## This Example Structure

```
dbt-jaffle/
├── *.dash.yaml          # Dashboard spec
└── dbt-stub/
    ├── manifest.json   # Real dbt manifest (simplified)
    └── customer_orders.csv  # Exported mart data
```

## Features

- **Real dbt manifest**: Includes proper lineage, schemas, and metadata
- **Multi-model lineage**: Seeds → Mart model dependency graph
- **Realistic data**: Customer orders with payments (25 orders, 15 customers)
- **Coordinated views**: Time-series brush filters bar charts

## Running

```bash
# From repo root
dvfc validate examples/dbt-jaffle/jaffle.dash.yaml
dvfc preview examples/dbt-jaffle/jaffle.dash.yaml
dvfc build examples/dbt-jaffle/jaffle.dash.yaml -o dist/jaffle
```

## Testing init from dbt

This example can be regenerated using:

```bash
cd examples/dbt-jaffle
dvfc init --from-dbt -o board-generated.yaml

# Compare with existing *.dash.yaml
diff *.dash.yaml board-generated.yaml
```

The `init --from-dbt` command:
1. Reads `dbt-stub/manifest.json`
2. Finds mart models (in `marts` schema or tagged with `mart`)
3. Scaffolds starter charts based on column types
4. Creates time-series + bar chart combinations

## Using with Your dbt Project

### Option A: Symlink (recommended for development)

```bash
cd my-dbt-project
mkdir -p dvfc/dbt-stub

# Symlink manifest (auto-updates on dbt run)
ln -s ../target/manifest.json dvfc/dbt-stub/manifest.json

# Symlink or copy CSVs
ln -s ../seeds/dashboard_data/*.csv dvfc/dbt-stub/

# Generate dashboard
cd dvfc
dvfc init --from-dbt -o *.dash.yaml
dvfc preview *.dash.yaml
```

### Option B: Copy (for stable/versioned dashboards)

```bash
cd my-dbt-project
mkdir -p dvfc/dbt-stub

# Copy manifest + data
cp target/manifest.json dvfc/dbt-stub/
cp seeds/dashboard_data/*.csv dvfc/dbt-stub/

cd dvfc
dvfc init --from-dbt -o *.dash.yaml
```
