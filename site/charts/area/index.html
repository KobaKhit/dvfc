The spec behind this chart

Copy this block into a dash file, point dataSource at your own data, and run dvfc build.

- id: habitable_momentum
  type: area
  title: The habitable-zone frontier
  dataSource: worlds
  encoding:
    x: { field: discovery_year, type: ordinal, label: Discovery year }
    y: { field: habitability_score, type: quantitative, aggregate: sum, label: Combined habitability signal }
  width: 680
  height: 360
