The spec behind this chart

Copy this block into a dash file, point dataSource at your own data, and run dvfc build.

- id: constellation_heatmap
  type: heatmap
  title: Where discoveries cluster in the sky
  dataSource: worlds
  encoding:
    x: { field: method, type: nominal, label: Method }
    y: { field: constellation, type: nominal, label: Constellation }
    color: { field: planet, type: quantitative, aggregate: count, label: Planet count }
  width: 680
  height: 520
