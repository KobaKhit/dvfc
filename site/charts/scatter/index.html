The spec behind this chart

Copy this block into a dash file, point dataSource at your own data, and run dvfc build.

- id: world_scatter
  type: scatter
  title: A universe of scales
  dataSource: worlds
  encoding:
    x: { field: equilibrium_k, type: quantitative, label: Equilibrium temperature (K) }
    y: { field: radius_earths, type: quantitative, label: Radius (Earths) }
    color: { field: mission, type: nominal, label: Discovery mission }
  width: 680
  height: 360
